## 커리큘럼 개요

이 사이트는 2026년 8월 28일 기준 Anthropic의 공개 Claude Code 문서를 우선합니다. UI, CLI 플래그, 실험 기능의 상태는 변경될 수 있으므로, 운영에 적용할 때는 각 챕터의 공식 문서 링크와 현재 설치 버전을 함께 확인하세요. 공개 근거가 없는 내부 이름·환경 변수·패키지는 사용법으로 다루지 않습니다.

## 학습 가이드

- **초급** (섹션 01-02): Claude Code의 기본 동작 원리와 도구 시스템
- **중급** (섹션 03-06): 에이전트, 권한, 메모리, 인터페이스의 심화 이해
- **고급** (섹션 07-10): 인프라, 연결성, SDK, 공개 상태와 제한을 고려한 운영 지식

각 챕터는 20~40분 분량이며, 섹션 마지막에 인터랙티브 퀴즈가 포함되어 있습니다.
